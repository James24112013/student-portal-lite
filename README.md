# Northstar Student Portal

A polished, responsive student dashboard inspired by modern school portals. It includes:

- Overview dashboard with a daily schedule
- Timetable navigation
- School notices
- Current grades snapshot
- Calendar navigation
- Responsive mobile sidebar

This version intentionally excludes attendance summaries and homework/assessment lists.

## Run locally

Open `index.html` in a browser, or serve the folder with any static web server.
